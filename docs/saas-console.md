# SaaS管理画面

`console.html` / `frontend/product.jsx` が現在の管理画面です。Cloudflare Accessで認証し、`/api/session` と同じデモアカウントのAPIに接続します。旧 `saas.html` へのアクセスもこの管理画面に送ります。

無料デモは編集者、有料デモは管理者。設備台帳、点検期限、CSVとJSONの移行、資料整理、Proバックアップ、管理者の操作履歴を利用できます。プラン比較は構内マップ上部のメニューからダイアログで開きます。表示カスタマイズには料金プランの操作を置きません。決済はありません。

以前の `saas.js` にある汎用OIDC / PKCEのコンソール実装は実験用として保持しています。今回のAccessメールSSOの実行経路では使いません。

地図の施設担当モードにある「設備分類」から、分類の追加・名前変更・削除ができます。使用中の分類を削除するときは、別の分類への移動または未設定を選んで保存します。設備・点検履歴は残り、分類定義と設備の値を同じDB更新で保存します。属性ロック中の設備がある場合は先に解除が必要です。追加した分類も、設備登録・絞り込み・分類別アイコンの割り当てに反映します。
