# PlantDeskの管理画面

`console.html` / `frontend/product.jsx` が現在の管理画面です。Cloudflare Accessで認証し、`/api/session` と同じデモアカウントのAPIに接続します。旧 `saas.html` へのアクセスもこの管理画面に送ります。

無料デモは編集者、有料デモは管理者。設備台帳、点検期限、CSVとJSONの移行、資料整理、Proバックアップ、管理者の操作履歴を利用できます。プラン比較は構内マップ上部のメニューからダイアログで開きます。表示カスタマイズには料金プランの操作を置きません。決済はありません。

以前の `saas.js` にある汎用OIDC / PKCEのコンソール実装は実験用として保持しています。今回のAccessメールSSOの実行経路では使いません。

地図の施設担当モードにある「設備分類」から、分類の追加・名前変更・削除ができます。使用中の分類を削除するときは、別の分類への移動または未設定を選んで保存します。設備・点検履歴は残り、分類定義と設備の値を同じDB更新で保存します。属性ロック中の設備がある場合は先に解除が必要です。追加した分類も、設備登録・絞り込み・分類別アイコンの割り当てに反映します。

標準設備アイコンは64種類。設備編集には現在のアイコンだけを表示し、「変更」から検索・8分野で絞り込める別ダイアログを開きます。追加した画像も同じ選択画面に表示し、設備の個別指定を分類の自動設定より優先します。

工事の関連設備は、設備名・設備ID・場所の検索、設備分類、図面で絞り込めます。選択済みの設備は条件を変えても保持され、選択タグから解除できます。候補は先頭100台まで表示し、検索対象は全設備です。

付箋は、サイズ変更つまみ上でもドラッグせずクリックすれば編集できます。施設担当モードでは、ホバー・キーボードフォーカス時（タッチ端末では常時）の「編集」ボタンからも開けます。

工事の作図・範囲編集に使う上位描画レイヤーは、その操作中だけ表示します。編集後に空のCanvasが残って付箋や設備のクリックを遮る問題を修正しました。

## 管理チーム向けワークフロー

業務画面は次の2つです。設備・工事台帳、設定・資料は別のナビゲーション群に置いています。

| 画面 | 目的・主な操作 |
| --- | --- |
| ダッシュボード | 期限超過・担当未定・確認待ちを見つけ、担当者の負荷や設備の要対応、直近の工事を確認する。件数から条件を絞ったタスクへ進む |
| タスク | 日々の作業・点検・修理・工事調整を、一覧・ボード・週間予定で実施する。案件、点検計画、点検予定・履歴、担当者、引き継ぎをここに集約する |

「点検・保守」は独立した業務画面ではなく、タスクの絞り込みビューです。点検待ち設備から対象設備を引き継いで点検・対応タスクを作成できます。登録済みの点検・修理があれば、その作業を開きます。点検の完了時は、従来どおり結果と履歴・必要なフォロー作業を一緒に保存します。旧 `#inspections` のブックマークはタスクの点検予定・履歴へ移動します。

一覧は担当者・期限・優先度・状態を直接編集できます。タスク名から右側の詳細を開き、一覧を残したまま別の作業へ切り替えられます。未保存の変更がある場合は破棄の確認を表示します。点検結果の記録、完了条件やチェック項目の確認を飛ばして完了することはできません。新規登録は一覧末尾でEnter、またはNキー。/キーで検索、Escapeで詳細を閉じます。

表示形式と種類・担当・状態・期限などの条件、並び順は個人設定としてDBに保存します。設備・工事一覧も列の選択と左右順、複数条件、ページサイズをD1の個人設定として保存し、設備の独自プロパティを列に追加できます。

操作の参考：[Asanaの一覧表示](https://help.asana.com/s/article/list-view)、[タスク詳細ペインとナビゲーション](https://help.asana.com/s/article/navigating-asana)。

工事一覧には削除済みの表示、登録・変更・削除履歴があります。作成・更新・削除の履歴は台帳更新と同時に追記し、取り込みやバックアップ復元も追跡します。導入前は遡れないため、現在の台帳をbaselineとして移行します。当時の添付は履歴参照が残り、削除できません。

工事の管理一覧と変更履歴、管理ダッシュボードは施設担当モードのみが利用でき、閲覧モードからAPIを直接呼んでも403になります。

## 表示と地図の整理

表示設定はカテゴリと検索から探せます。アイコンと工事吹き出しは基準サイズ、固定／緩やか／図面倍率、最小倍率を指定できます。地図・設備・工事・付箋・操作・パネルの各設定、用途別／個人用プリセット、設定JSONの持ち出しも利用できます。

任意レイヤーは複数種類の項目を含み、表示を切り替えられます。設備分類での自動生成・一括移動を用意しています。非公開レイヤーの工事・付箋・図面リンクは閲覧モードへ送信しません。

図面リンクは対角2点を指定して作成します。ダブルクリックで子図面へ移動し、パンくずと戻るで元の位置へ戻ります。公開する場合は、移動先図面を閲覧可能にすることも確認して保存します。

## 案件と工程

「タスク → 案件・改善」で案件ごとの責任者・期間・進捗を確認できます。作業には案件・親作業・先行作業・依頼元・完了条件を設定できます。未完了の先行作業、子作業、完了条件の確認をサーバーでも検証します。Notionとの役割分担は [業務管理の案内](team-workflow.md) を参照してください。
