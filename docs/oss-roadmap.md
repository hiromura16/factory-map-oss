# Factory Map OSS / SaaS roadmap
## 現在の位置
既存デモの機能を保持し、稼働中サービスとは独立した作業コピーで開発しています。会社固有情報を含まない架空のサンプルのみを配布します。

### 実装の境界
- 既存アプリ: React / Leaflet、Rust / Axum、PostgreSQL。工事、設備台帳、点検履歴、写真、PDF、DXF、付箋、REST API。
- UI拡張: 折りたたみ、配色・密度、追加画像アイコンなど。ブラウザー内の設定と共有DB設定を明示して区別。
- SaaS基盤: Cloudflare Workers + D1。段階的に API と組織境界を実装。既存 UI / Rust API と完全互換の移行完了を意味しません。
- 課金: デモのみ。実決済、請求、カード保存、サブスクリプション契約は行いません。
- SSO / SCIM: 本番IdPとの検証が完了するまで対応済みと表示しません。

## プラン設計案（価格未設定）
無料: 基本編集、少数図面・設備、標準テーマ。
Pro: 図面・設備上限拡張、独自アイコン、テーマ、カスタム属性、履歴出力。
Organization: SSO、SCIM、役割管理、監査履歴、保持期間ポリシー。
UI表示制限だけで課金制御を成立させないこと。SaaS API側でテナント別に検査し、同時リクエストでも上限を超えない必要があります。
セルフホスト版の機能を不透明なライセンスチェックで停止させない方針です。具体的な料金・上限は正式公開前に決定します。

## 次のリリースゲート
1. テナント間アクセス拒否、権限、セッション失効、CSRF、ファイル所有権を検証。
2. PostgreSQL / 旧IndexedDBデータのdry-run、重複検出、履歴日時・ID保持、添付本体の照合を検証。
3. UIとWorker APIの統合テスト、キーボード・スマホ・パネル開閉の回帰。
4. OIDCのstate/nonce/PKCE、署名・issuer/audience検証、IdP無効化を実機確認。
5. SCIM provisioning/deprovisioningと再送、フィルター、組織権限をIdPで検証。
6. 独立レビュー、依存ライセンスと秘密情報スキャン、公開用クリーンアーカイブ。
7. 帰宅後、所有者がCloudflare設定・ドメイン取得を実施。本番デプロイは別工程。
