# Factory Map OSS / SaaS

- Cloudflare Access SSOと無料／有料管理者デモの切替。
- 地図・工事・台帳・点検・付箋とD1 APIの接続。

- API・DB・ブラウザの統合検証。詳細はREADMEを参照。
