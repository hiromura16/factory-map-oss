ワークスペース管理

組織・データ移行・利用枠をひとつの場所で。課金はモックです。

このコンソールは新しい D1 API 専用です。既存の地図画面は旧 API のため、ここで選んだ組織やデータとはまだ連携していません。SSO の実 IdP 接続・SCIM・本番運用は未検証です。

帰宅後の接続設定を待っています

Cloudflare と IdP の設定はまだ変更していません。公開設定 saas-config.json を配置すると接続できます。秘密鍵・client secret をこのファイルに入れないでください。

アカウント

未接続

登録・認証は選択した IdP で行います。ログインボタンを押すまでは移動しません。

ログアウトはコンソール内のトークンを破棄します。IdP 全体のセッションは終了しません。再読込後は再ログインが必要です。

組織

新規作成にはサーバー側の ALLOW_REGISTRATION が必要です。

利用枠と課金モック

料金は発生しません。変更すると D1 側の利用枠に反映されます。所有者のみ変更でき、上限超過のダウングレードはデータを削除せず拒否されます。

旧データからの移行

JSON の検証・プレビュー後、空の組織にのみ取り込めます。添付ファイル本体の移行はまだ未接続です。既存レコードは上書きしません。
